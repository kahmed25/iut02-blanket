╚═══════════════════════════════════════════════════════════════╝

📋 COMPLETE LOGIN FLOW:

1. User visits: http://localhost:3000/login
   ↓
2. Clicks "Continue with Google"
   ↓
3. Redirects to: http://localhost:8000/auth/login/google
   ↓
4. Backend redirects to: Google OAuth page
   ↓
5. User signs in with Google
   ↓
6. Google redirects to: http://localhost:8000/auth/callback/google
   (with authorization code)
   ↓
7. Backend:
   - Exchanges code for access token
   - Gets user info from Google
   - Creates/updates user in database
   - Generates JWT tokens
   ↓
8. Backend redirects to: http://localhost:3000/auth/success
   (with access_token & refresh_token in URL)
   ↓
9. Success page:
   - Stores tokens in localStorage
   - Loads user data
   ↓
10. Redirects to: http://localhost:3000/
    ✓ USER IS NOW LOGGED IN!

✅ WHAT'S STORED:

After login, localStorage contains:
- iut02_access_token: JWT token (expires in 15 min)
- iut02_refresh_token: JWT token (expires in 7 days)

Database (backend/auth.db) contains:
- Your user record (email, name, provider)
- Your session record (refresh token, expiry)
